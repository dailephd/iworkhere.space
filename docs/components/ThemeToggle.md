# ThemeToggle

The Themes trigger has no icon. Exactly four choices come from the canonical registry: System, Light, Dark, One Dark. Options are native keyboard-accessible buttons with listbox/option semantics and aria-selected. Selection persists through ThemeStorage and applies through ThemeRuntime. Color changes never alter layout. See ../modules/ThemeToggle.md and ../DESIGN.md.


### Component-color correction (Delivery 1 visually approved 2026-10-03)

Exactly four choices: System, Light, Dark, One Dark. Themes trigger uses contrasting shell roles without an icon. Floating options use body surfaces/text, selected tint and aria-selected; native buttons support keyboard selection.


### Island/material candidate

One Dark popover uses structural glass; plain themes use a solid surface. Four native choices, persistence and keyboard behavior remain unchanged.
